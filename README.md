# MATA bus feed

Records where every MATA (Memphis) bus is, every 10 seconds, shows it on a
live map, and keeps the history to answer which routes run behind, which
days are bad, and how many people are riding.

Everything known about the project (design, data sources and formats,
findings, open questions, how to run it, the work log) is in
[`knowledge/`](knowledge/index.md), a bundle in the
[Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format)
(v0.2). Start at [`knowledge/index.md`](knowledge/index.md).
