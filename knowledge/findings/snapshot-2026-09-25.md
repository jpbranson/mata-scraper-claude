# Rebuilt on 2026-10-05

On 2026-10-05 a `snapshot.py` run copied the current `data/` into this
folder by mistake, over the 20:21 copy. It was rebuilt from that fuller
copy by keeping only what the original held: every record up to the
original copy's last poll (`observed_at` 1790385690, Fri 20:21:30), except
arrivals logged at that poll (`t` before it, since the poller writes an
arrival one poll later), and `stops.csv` from git (`HEAD`, the version of
2026-09-24). `page_data.py` as it was then reproduced the page's
`out/page_data.json` and `out/numbers.txt` byte for byte from the rebuilt
copy. `data/latest.json`
was rebuilt from that last poll's rows, without the buses' trails; `[Q3]` on
it still gives 25 buses and 95 riders. `data/detours/` holds the one detour
record fetched by then (20:12), which `analysis.sql`'s `rider_messages` view
needs.[^rebuild]
